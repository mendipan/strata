# Strata examples

These are bounded synthetic inputs, not application defaults or evidence about a deployed product.

- The root JSON examples use the booking profile to show owned duration/reminder proposals, a deliberate conflict, explicit selection and Release inheritance. `npm run demo` runs this locally: the accepted hold lasts 900 seconds, a single reminder fires at 840, competing holds are refused, and a new hold is possible after expiry. Full traces stay under `.strata/`.
- `bootstrap-content-v2.json`, `L-content-v2.json` and `content-review-v2.json` show opt-in content and exact authoring review. See the [Block contract](../docs/BLOCK_CONTRACT.md).
- `source-manifest.json` and `distill-proposal.json` illustrate supplied-proposal distillation and source traceability. See [translation](../translation/README.md).
- `agent-session.json` is a portable fixture CLI session. The [agent skill](../agent/strata/SKILL.md) describes the protocol; a host still assigns identities and permissions.
- `replay/synthetic-run.json` is generated by `node dist/scripts/generate-example-replay.js` from local deterministic engine events, including the 1200-second choice and the same owner's reminder repair to 1140. It is never live/human/cloud evidence. `npm run demo:replay` serves it read-only.

The separate [counter fixture](../tests/fixtures/counter/bootstrap.json) exercises different vocabulary/topology through the same engine. Neither profile provides arbitrary app synthesis. Keep real application sources, connection registries and generated results in their own workspace.
