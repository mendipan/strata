# Developer preview roadmap

This describes source scope, not a hosted service or delivery schedule. Implementation alone does not establish installation acceptance. See [Studio status](studio/STATUS.md) and [implemented contract](IMPLEMENTED_CONTRACT.md).

| Area | Implementation | Verified scope | Planned |
| --- | --- | --- | --- |
| Intent source control | Blocks, Layers, exact composition, Resolutions, evidence and Release gates | Finite local fixtures and authority/persistence regressions | Broader profiles and independently authenticated evidence |
| Studio authoring | Reads, typed new-Block requirements, advanced JSON, exact draft Save and reviewer handoff | Synthetic HTTP/browser and restart checks | More guided conflicts, criteria and guardian authoring |
| Browser ownership/storage | Linux operator-approved enrollment/seal, sessions, encrypted token custody, namespace consent and exact-index import | Protected-state fixtures and bounded installation evidence | Operator lifecycle/migration tools and broader host qualification |
| Native Codex | Pinned 0.162.1, private home, proposal, explicit Save, recovery and Stop | Real proposal saved privately; bounded recovery and fresh Stop; instrumented runtime and packaged identity checked separately | Additional uninstrumented package and independent-host acceptance |
| Claude | Pinned SDK bridge and encrypted local API-key custody | Synthetic protocol/refusal tests; no equivalent real proposal/Stop acceptance claimed | Separate confinement and attended provider qualification under SDK terms |
| Profiles | Finite recipes and CLI/UI components behind explicit authority | Declared-profile and accepted-source fixtures | Complete integrated Profile → Build after launch |
| Local Build | Bounded launcher/persistence/packaging behind installation gates | Component and packaging fixtures within declared scope | Integrated installation, browser and recovery acceptance after launch |
| Cloud execution examples | Plans, budgets, retention and bounded cleanup receipts | Historical bounded execution plus synthetic management regressions | Broader workload/provider/resource qualification |
| Reconstruction | Prepared source-to-intent proposals and finite materialization | Fresh evidence per finite realization | Broader reconstruction research; no universal/lossless guarantee |
| Distribution | Apache-2.0 source, upstream notices, code/runner manifests | Local package, license and scrub checks per candidate | Reviewed public snapshot and independent installation feedback |

The static public website is separate from Studio. Public source does not enroll an owner, grant cloud access, approve a private draft, issue a Release or deploy code.
