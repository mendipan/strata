# Studio operation and recovery behavior

The preview retains bounded corrections for failures reproduced during attended use. Private deployment/test ledgers and screenshots remain outside public source.

- Exact nginx authoring operation/preview locations have a 1 MiB ceiling, retaining the small default and proxy restrictions. Installed syntax and handling require host qualification.
- HTML, malformed success and lost replies retain the original request and block unknown-outcome resubmission. Receipt inspection reconciles results; an absent receipt alone does not prove no provider effect.
- Session refusal clears stale connected/command claims. Visible focused errors preserve unsaved fields and offer copy/separate-tab sign-in. Refresh does not automatically replay or persist unsaved content.
- Record visibility refusal is distinct from source failure. Imported records retain authors; readable content does not grant private Review access.
- Result links select the exact returned revision; older revisions remain immutable.
- Partial registered/nonempty repositories expose original outcomes and an operator handoff. Automatic adoption, overwrite and deletion are unsupported.

Native and real local browser fixtures cover saves above the default proxy limit, HTML 413/502, malformed replies, committed saves with lost delivery, receipt inspection, revision reload, expiry, focus/mobile and zero duplicate dispatch. Synthetic providers establish no live deployment result. Existing models/grants still govern publication, evidence and Release; these fixes add no authority.
