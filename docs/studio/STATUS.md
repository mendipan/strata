# Studio developer preview

Studio browses exact intent references and supports configured authoring, review and finite validation. Start with [Getting started](../GETTING_STARTED.md), the [local contributor starter](../CONTRIBUTOR_STARTER.md), or [self-hosting](SELF_HOSTING.md). The separate static public website explains Strata; it does not host Studio or provide an account service.

## Implemented scope

- Blocks, owned private Layer drafts, immutable published revisions, exact composition, explicit conflict decisions, candidate-bound evidence and Release gates.
- Typed new-Block requirements, advanced JSON, exact previews and reviewer handoff. A supplied digest establishes content integrity, not sender identity or a sharing grant.
- Linux browser-owner enrollment with independent operator approval/seal, sessions, encrypted Artifacts credentials, namespace consent, discovery/creation and exact-index import. Session, source, author and provider authority remain distinct.
- A finite first-project collection template with explicit named roles and bounded measurement. Imported history retains its authors; a fresh author cannot overwrite another author's private draft.
- Paired Windows agents with native preflight, private state, model discovery, bounded context, proposal preview, explicit Save and original-operation recovery. Existing paired local connections establish selected-project context on Start conversation; other provider connections retain separate consent.
- Profile and Local Build backend/CLI/UI components behind explicit installation and accepted-source contracts. Packaging them does not provision the integrated workflow.

The [roadmap](../ROADMAP.md) separates implementation, verified scope and planned work. [Implemented contract](../IMPLEMENTED_CONTRACT.md) remains the engine reference.

## Demonstrated scope

Synthetic engine/HTTP/browser suites cover exact references, private visibility, revoked sessions, CAS/idempotency, unknown outcomes, finite measurement, draft saving and restart. Historical aggregate counts do not claim that every current file was rerun together.

Native **Codex 0.162.1** returned a real proposal that a human explicitly saved as a private draft. Bounded original-result recovery used original native identifiers without another inference. A separate fresh Stop test observed native interrupt success, interrupted completion, cancelled result delivery and matching local/Studio readback. That Stop run used instrumented compiled modules; installed ZIP inventory and source identity were checked separately. It does not establish another uninstrumented packaged-runner acceptance run, general Windows compatibility or Claude parity. See [Windows qualification](../agents/STUDIO_CODEX_WINDOWS_STARTUP.md).

A saved proposal is private intent awaiting review. It is not publication, an accepted candidate, validated implementation or Release. No private example draft is included here.

## Installation and limits

Self-hosting requires Linux Node 22+, HTTPS, protected disjoint owner/key/credential/project/accounting state and your own Artifacts account, namespace and token. The reader service's resource envelope does not qualify named execution or arbitrary workloads. Startup creates no provider authority or provider work.

Binary/schema identity, Windows custody/confinement, authentication, model availability, actual ingress, interruption and recovery require qualification per installation. Schema preflight is not isolation proof. Claude has separate terms and acceptance. Timeout or browser abort does not prove native/provider work or billing stopped.

Complete integrated **Profile → Build is post-launch work**. There is no one-click installation, unattended operation or general reconstruction promise. A Release preserves reviewed intent and evidence; deployment is separate.
